# NIRE SMP Website
เว็บไซต์ NIRE SMP สำหรับ GitHub Pages

## วิธีใช้งาน
1. สร้าง GitHub repository
2. อัปโหลด `index.html`
3. ไปที่ Settings → Pages
4. เลือก Deploy from a branch → main → / (root)
5. บันทึก แล้วรอ GitHub สร้างเว็บไซต์

ก่อนใช้งานจริง ให้แก้ IP เซิร์ฟเวอร์และลิงก์ Discord ใน `index.html`
